# CWHEO-2024 Open Repository

## 项目简介

本仓库整理了 CWHEO-2024 土壤参量相关工作的算法代码、实验过程文件和部分结果，用于学术交流与复现参考。

## 目录说明

- `5.其他(算法代码)/`：主要 Python 代码（特征提取、模型对比、最优模型训练、反演、制图）。
- `4.反演结果原图/`：反演输出原图（ENVI 格式与部分图件）。
- `*.docx`：比赛提交材料与说明文档。

## 开源协议

本仓库代码与自有文档采用 MIT License，见 [LICENSE](LICENSE)。

## 开源范围与限制（务必阅读）

仓库内存在比赛数据相关文件，且根目录包含 `比赛数据使用协议_正规版V2.docx`。根据该协议，部分数据和衍生结果可能受主办方条款约束。  
如果你准备将本仓库公开到 GitHub，建议按下列方式处理：

- 保留可公开的代码与自写文档。
- 对比赛原始数据、受限衍生数据、模型权重、报名材料做脱敏或改为下载说明。
- 在论文和仓库中明确数据来源与使用限制。

## 运行环境建议

- Python 3.10
- 常用依赖：`numpy`, `pandas`, `scikit-learn`, `scipy`, `matplotlib`, `openpyxl`, `tqdm`, `joblib`, `spectral`, `matplotlib-scalebar`

可先创建虚拟环境，再安装依赖：

```bash
pip install -U numpy pandas scikit-learn scipy matplotlib openpyxl tqdm joblib spectral matplotlib-scalebar
```

## 复现建议

- 优先从 `5.其他(算法代码)/` 内各子目录按流程运行：原始数据处理 -> 光谱特征选择 -> 模型对比/最优模型 -> 反演与制图。
- 若缺失外部影像数据，请根据目录中的链接说明文件获取对应数据。
- 建议统一随机种子并记录依赖版本，保证可复现性。
