该脚本旨在对Excel文件中的数据进行特征选择，特别是针对有机质和含盐量相关的光谱特征。整个过程包括读取数据、使用随机森林回归器通过差分进化优化进行特征选择，并将选定的特征保存到新的Excel文件中。以下是对脚本各部分的详细解析：
该脚本的主要流程如下：

读取数据：从指定的Excel文件中读取数据，并删除任何包含缺失值的行。
特征选择：对于每个指定的目标变量（如有机质和含盐量），使用随机森林回归器评估特征的重要性，并通过差分进化算法优化选择出最重要的前N个特征。
保存结果：将选定的特征和目标变量保存到新的Excel文件中，便于后续分析或使用。
报告执行时间：在脚本结束时，输出整个流程的执行时间，帮助评估效率。

1. 导入必要的库

   
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from scipy.optimize import differential_evolution
from openpyxl import Workbook
from tqdm import tqdm
import time
pandas (pd)：用于数据操作和分析，特别是读取和处理Excel文件。
numpy (np)：用于数值运算和处理数组数据。
RandomForestRegressor 来自 scikit-learn：用于构建回归模型以评估特征的重要性。
differential_evolution 来自 scipy.optimize：用于执行优化以选择特征。
openpyxl：用于创建和写入Excel工作簿。
tqdm：用于在处理过程中显示进度条。
time：用于跟踪脚本的执行时间。
2. 读取Excel数据


def read_excel_data(file_name):
    df = pd.read_excel(file_name)
    df = df.dropna()
    return df
功能：从Excel文件中读取数据并删除包含缺失值的行。
参数：
file_name：要读取的Excel文件的路径。
过程：
读取数据：使用 pd.read_excel 将数据加载到pandas的DataFrame中。
处理缺失值：df.dropna() 删除任何包含 NaN 值的行，以确保数据的完整性。
返回值：一个已清理且不包含缺失值的DataFrame。
3. 特征选择

        

def feature_selection(df, target_col, n_features=25):
    X = df.iloc[:, 3:].values  # 从第4列开始选择特征
    y = df[target_col].values

    rf = RandomForestRegressor(n_estimators=100, random_state=42)

    def objective_function(weights):
        selected_features = X[:, weights > 0.5]
        rf.fit(selected_features, y)
        feature_importances = rf.feature_importances_
        return -np.sum(feature_importances)

    bounds = [(0, 1)] * len(df.columns[3:])  # 为每个特征定义权重范围

    result = differential_evolution(objective_function, bounds, maxiter=100, seed=42)
    best_weights = (result.x > 0.5)

    rf.fit(X[:, best_weights], y)
    feature_importances = rf.feature_importances_
    top_n_features = np.argsort(feature_importances)[-n_features:]
    return df.columns[3:][best_weights][top_n_features]  # 返回前N个特征名称
功能：使用随机森林回归器通过差分进化算法优化选择与目标变量相关的重要特征。
参数：
df：包含数据集的DataFrame。
target_col：目标列的名称，即要进行特征选择的目标变量。
n_features：要选择的前N个特征数量（默认为25）。
过程：
特征和目标变量分离：
X：提取所有特征列，从第4列开始（假设前三列为非特征数据，例如ID、日期等）。
y：提取目标变量的值。
随机森林设置：
初始化一个 RandomForestRegressor，设置100棵树（n_estimators=100）和固定的随机种子（random_state=42）以确保可重复性。
优化目标函数：
功能：评估一组特征的总重要性，目标是最大化特征重要性之和，因此返回负值以转换为最小化问题。
输入：一个权重向量，每个权重对应一个特征。权重大于0.5的特征被选中。
过程：
特征选择：选择权重大于0.5的特征。
模型训练：在选择的特征上训练随机森林模型。
重要性计算：获取训练后模型的特征重要性。
返回值：特征重要性之和的负值，以便优化器进行最小化处理。
差分进化优化：
功能：寻找最优的权重组合（特征选择），以最大化特征重要性之和。
参数：
objective_function：要最小化的函数。
bounds：每个特征权重的范围（0到1）。
maxiter=100：优化器的最大迭代次数。
seed=42：随机数生成器的种子，以确保可重复性。
结果：优化器找到的最佳权重集合。
最终特征选择：
阈值处理：将优化后的权重转换为布尔掩码，权重大于0.5的特征被选中。
模型训练：在选中的特征上重新训练随机森林模型。
重要性获取：获取训练后模型的特征重要性。
选择前N个特征：根据重要性排序，选择前N个特征。
返回值：来自DataFrame的前N个选定特征的名称。
返回值：一个包含前N个选定特征名称的列表。
4. 将选定特征保存到Excel


def save_selected_features_to_excel(file_name, df, target_col, selected_features):
    wb = Workbook()
    ws = wb.active

    # 写入目标列
    ws.cell(row=1, column=1, value=target_col)
    for i, value in enumerate(df[target_col].values):
        ws.cell(row=i+2, column=1, value=value)

    # 写入选择的特征
    for j, feature in enumerate(selected_features):
        ws.cell(row=1, column=j+2, value=feature)
        for i, value in enumerate(df[feature].values):
            ws.cell(row=i+2, column=j+2, value=value)

    wb.save(file_name)
功能：将目标列和选定的特征列保存到一个新的Excel文件中。
参数：
file_name：要保存的Excel文件的名称或路径。
df：包含数据的原始DataFrame。
target_col：要保存的目标列的名称。
selected_features：选定的特征名称列表。
过程：
工作簿设置：
使用 Workbook() 创建一个新的Excel工作簿。
访问活动的工作表 (ws)。
写入目标列：
将目标列的名称写入第一个单元格 (A1)。
遍历目标列的每个值，并从第二行开始依次写入。
写入选定的特征：
遍历每个选定的特征。
将特征名称写入第一行（作为表头）。
遍历每个特征的值，并从第二行开始依次写入对应的列。
保存工作簿：
使用 wb.save(file_name) 将工作簿保存到指定的文件名。
5. 主函数

        

def main(input_file_name):
    start_time = time.time()
    df = read_excel_data(input_file_name)
    nutrients = ['有机质(g/kg)', '含盐量(g/kg)']
    output_files = ['2.有机质光谱特征.xlsx', '2.含盐量光谱特征.xlsx']

    for nutrient, output_file in zip(tqdm(nutrients, desc='Feature Selection Progress'), output_files):
        selected_features = feature_selection(df, nutrient)
        save_selected_features_to_excel(output_file, df, nutrient, selected_features)

    end_time = time.time()
    elapsed_time = end_time - start_time
    hours, rem = divmod(elapsed_time, 3600)
    minutes, seconds = divmod(rem, 60)
    print(f"程序运行时间：{int(hours):02}:{int(minutes):02}:{seconds:.2f}")
功能：协调整个工作流程，包括读取数据、对指定的目标变量进行特征选择、保存结果，并报告执行时间。
参数：
input_file_name：包含数据集的输入Excel文件的名称或路径。
过程：
记录开始时间：使用 time.time() 记录当前时间，以便后续计算总执行时间。
读取数据：调用 read_excel_data 函数加载并清理数据集。
定义目标变量和输出文件：
nutrients：目标列的列表，此处为 '有机质(g/kg)' 和 '含盐量(g/kg)'。
output_files：对应的输出Excel文件名，用于保存每个目标变量的选定特征。
特征选择和保存：
使用 zip 和 tqdm 迭代目标变量和对应的输出文件，并显示进度条（标题为 'Feature Selection Progress'）。
对于每个目标变量：
调用 feature_selection 函数获取前N个选定的特征。
使用 save_selected_features_to_excel 函数将选定的特征和目标变量保存到指定的Excel文件。
记录结束时间：处理完成后记录当前时间。
计算并显示执行时间：
计算总共耗时 (elapsed_time)。
将耗时转换为小时、分钟和秒。
打印执行时间，格式为 程序运行时间：HH:MM:SS.SS。

if __name__ == '__main__':
    input_file_name = '化验数据及对应反射率数据.xlsx'
