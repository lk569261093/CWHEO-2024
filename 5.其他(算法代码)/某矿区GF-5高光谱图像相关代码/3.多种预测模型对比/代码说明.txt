2. 读取Excel数据文件

        

# 读取Excel文件
file_path = '2.有机质光谱特征25.xlsx'

解释：
从路径 '2.有机质光谱特征25.xlsx' 读取Excel文件，并将其存储为Pandas的DataFrame data。该文件包含光谱特征和对应的土壤有机质含量数据。
3. 提取特征与目标变量

        

# 提取土壤养分数据和光谱数据
y = data['有机质(g/kg)']
X = data.drop(columns=['有机质(g/kg)'])
解释：
y： 目标变量，表示土壤有机质含量（有机质(g/kg)）。
X： 特征矩阵，包含所有其他列（假定为光谱特征），通过删除目标列得到。
4. 使用互信息法进行特征选择


# 互信息法选择特征
mi = mutual_info_regression(X, y)
mi_series = pd.Series(mi, index=X.columns, name='互信息值')
mi_series.to_excel('互信息值.xlsx', index=True)

selected_features_mi = X.columns[mi > 0.3]
X_selected_mi = X[selected_features_mi]
解释：
互信息回归 (mutual_info_regression)： 测量 X 中每个特征与目标变量 y 之间的依赖性。
存储互信息值： 创建一个Pandas Series mi_series，将互信息值与特征名对应，并保存为Excel文件 '互信息值.xlsx'，便于后续查看。
特征选择阈值： 选择互信息值大于 0.3 的特征，存储在 selected_features_mi 中。
X_selected_mi： 包含通过互信息法选择的特征的特征矩阵。
备注： 互信息能够捕捉特征与目标变量之间的非线性关系，适用于回归任务中的特征选择。

5. 使用递归特征消除法（RFE）进行特征选择

        

# 递归特征消除法选择特征
ridge_for_rfe = Ridge()
rfe = RFE(estimator=ridge_for_rfe, n_features_to_select=10)
rfe.fit(X, y)
selected_features_rfe = X.columns[rfe.support_]
X_selected_rfe = X[selected_features_rfe]
解释：
岭回归估计器： 使用岭回归 (Ridge()) 作为RFE的基估计器。
递归特征消除法 (RFE)： 逐步消除不重要的特征，通过迭代方式减少特征数量。
n_features_to_select=10： 指定RFE选择前10个最重要的特征。
训练RFE： 在整个数据集 X 和 y 上拟合RFE。
选择特征： selected_features_rfe 包含通过RFE选择的10个特征的名称。
X_selected_rfe： 包含通过RFE选择的特征的特征矩阵。
备注： RFE是一种包裹式方法，根据基估计器的重要性反复选择特征，适用于高维数据的特征选择。

6. 数据预处理（标准化）

        

# 数据预处理

scaler_y = StandardScaler()

X_scaled_rfe = scaler_X.fit_transform(X_selected_rfe)
y_scaled = scaler_y.fit_transform(y.values.reshape(-1, 1)).flatten()
解释：
标准化： 将特征和目标变量进行标准化处理，移除均值并缩放到单位方差。
scaler_X： 用于标准化特征矩阵。
scaler_y： 用于标准化目标变量。
X_scaled_mi： 通过互信息法选择的特征矩阵进行标准化后的数据。
X_scaled_rfe： 通过RFE选择的特征矩阵进行标准化后的数据。
y_scaled： 标准化后的目标变量。
备注： 标准化对于一些对特征尺度敏感的模型（如岭回归、支持向量机和神经网络）至关重要。

预测： 对训练集和测试集进行预测，分别得到 y_train_pred_ridge_mi 和 y_test_pred_ridge_mi。

11. 模型评估函数定义

        

# 评估模型
def evaluate_model(y_true, y_pred):
    slope, intercept, r_value, p_value, std_err = linregress(y_true, y_pred)
    r2 = r_value**2
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    mae = mean_absolute_error(y_true, y_pred)
    return r2, rmse, mae
解释：
evaluate_model： 定义了一个评估函数，计算三个指标：
R²分数（r2）： 通过线性回归的斜率得到。
均方根误差（RMSE）： 评估预测值与真实值之间的偏差。
平均绝对误差（MAE）： 评估预测值与真实值之间的绝对偏差。
